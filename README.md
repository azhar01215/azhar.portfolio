# MD Azhar Mehemud Molla — Personal Portfolio 🎮⚡

A premium, retro-gaming and cyber-futuristic personal developer portfolio website designed for recruiters, hackathons, and software engineering opportunities.

Built with **React 19**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and the **Web Audio API**.

---

## 🌟 Key Features

- 🖥️ **AZHAR_OS Boot Sequence**: Cinematic terminal boot loader with module validation, ASCII progress indicator, and instant skip options.
- 🎛️ **Futuristic HUD Navbar**: Dynamic scrollspy, CRT scanline toggle, and synthesized Web Audio 8-bit sound fx engine.
- 🕹️ **Arcade Player Profile**: Level 04 AIML stats, character attributes, XP progress bar, spring-physics counters, and tactical hobbies.
- 🌳 **Synaptic Skill Tree**: Interactive node graph spanning AI & Machine Learning, Web Development, and Developer Arsenal with real-time Synapse Inspector.
- 🎯 **Mission Control Cards**: 3D mouse-tilt cards with category filtering, performance metrics, and deep inspection modal dossiers.
- 🏆 **Achievements Unlocked**: Steam/Arcade trophy cabinet with lock-to-unlock scroll animations, audio fanfare, and confetti bursts.
- 🗺️ **Player Journey**: Glowing vertical cyber conduit connecting B.Tech CSE (AIML), ARDENT industrial internships, and CST Diploma milestones.
- 📟 **Quantum Comm Conduit**: Terminal CLI emulator (`help`, `about`, `skills`, `missions`, `contact`) and encrypted transmission dispatch form.
- 🎯 **Custom Desktop Cursor**: Trailing dual-ring targeting cursor with interactive crosshairs and magnetic hover states.

---

## 🛠️ Tech Stack

- **Framework**: [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) + [Canvas Confetti](https://github.com/catdad/canvas-confetti)
- **Audio Engine**: Web Audio API (Synthesized 8-bit sound fx, zero external audio assets)
- **Icons**: [Lucide React](https://lucide.dev/) + Custom SVGs
- **Typography**: Google Fonts (Orbitron, Space Grotesk, Press Start 2P, Silkscreen, JetBrains Mono)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/azhar01215/azhar.portfolio.git
   cd azhar.portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
